# For LLMs

a11y-hud provides machine-readable documentation endpoints so AI assistants and LLM-powered tools can understand this library accurately.

## llms.txt

A concise index of the documentation — titles, descriptions, and links. Follows the [llms.txt standard](https://llmstxt.org/){target="_blank"}.

<a href="/a11y-hud/llms.txt" target="_blank" class="llm-link">llms.txt</a>

## llms-full.txt

The full content of every documentation page in a single plain-text file. Best for feeding directly into a context window.

<a href="/a11y-hud/llms-full.txt" target="_blank" class="llm-link">llms-full.txt</a>

## Per-page Markdown

Append `.md` to any documentation URL to get that page as raw Markdown.

<a href="/a11y-hud/guide/react.md" target="_blank" class="llm-link">/guide/react.md</a>
